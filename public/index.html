Flagship Case Study

Paper OCR LLM: KYC/KYB document intelligence at scale

How a document-classification bottleneck at a B2B fintech serving 600,000+ SMEs became a 4-second, 99%-accurate pipeline.

01

Problem

Paper.id's onboarding required manual review of ID cards, Tax ID numbers, and business registration documents for every new business customer. Manual KYC/KYB review was slow, inconsistent across reviewers, and became the biggest bottleneck to onboarding speed as the platform scaled.

02

Research

Evaluated traditional OCR engines against LLM-assisted extraction. Traditional OCR handled clean scans well but broke down on skewed, low-light, or handwritten fields common in real submissions — while pure LLM extraction was accurate but too slow and costly to run on every field independently.

03

Architecture

Designed a hybrid pipeline: a lightweight classifier routes each document to the right handler, an image-enhancement stage (brightness, contrast, sharpness, skew correction via OpenCV) prepares it for extraction, and an LLM-backed extraction layer parses structured fields — all served through FastAPI.

04

Workflow

Document upload → type classification → image enhancement → field extraction (LLM + OCR) → confidence scoring → structured output. Low-confidence extractions are flagged for lightweight human review rather than blocking the pipeline.

05

Implementation

Built and iterated the pipeline in Python with FastAPI for serving, OpenCV for preprocessing, and LLM APIs for extraction. The enhancement stage alone lifted downstream OCR accuracy by 10%, cut file size 40%, and increased processing speed 50% before extraction even ran.

06

Results

The system reached 99% OCR accuracy with processing time down to roughly 4 seconds per document — turning a manual review bottleneck into a near-instant onboarding step, at meaningful scale.

Lessons learned

The unglamorous preprocessing step mattered more than the model choice — most of the accuracy gain came before extraction ever ran. And routing by confidence, rather than trying to force one model to be perfect, let the system fail gracefully instead of silently.
